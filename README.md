# 电商比价自动化工作流

## 项目概述

本项目是一个功能完善的电商比价自动化工作流，用于筛选和验证供应链商品是否满足全网低价要求（以平台型供应链为主）。该工作流支持从多种数据源导入商品信息，自动在多个电商平台搜索价格，并进行价格对比和分析。

## 功能特性

- **商品数据整理**：支持从CSV/Excel文件导入或从供应链网址抓取商品信息
- **多平台价格采集**：支持在慢慢买、拼多多、返利网等平台搜索商品价格
- **搜索结果验证**：验证商品规格一致性、价格有效性和链接可访问性
- **数据汇总与对比**：生成详细的价格对比表格，支持导出为Excel/CSV格式
- **可配置性**：允许用户自定义平台列表、搜索参数、验证规则及输出格式
- **错误处理**：提供完善的错误处理和日志记录机制

## 使用方法

### 基本用法

```bash
# 从文件导入商品数据，导出为Excel格式
python run.py path/to/products.xlsx

# 从URL抓取商品数据，导出为CSV格式
python run.py https://example.com/products --output-format csv
```

### 配置说明

可在 `src/config/config.py` 中修改以下配置：

- **PLATFORMS**：电商平台配置，可添加或禁用平台
- **SEARCH_RETRY_LIMIT**：搜索重试次数
- **VALIDATION_RETRY_LIMIT**：验证重试次数
- **REQUEST_DELAY**：请求延迟（秒），用于反爬
- **OUTPUT_DIR**：输出文件目录
- **LOG_DIR**：日志文件目录

### 输入数据格式

#### 文件输入

支持CSV和Excel格式，至少包含以下列：
- 商品名称
- 规格参数
- SKU编码
- 供应链价格

#### URL输入

支持从供应链网站抓取数据，需要根据具体网站结构调整 `data_loader.py` 中的解析逻辑。

### 输出结果

输出文件包含以下信息：
- 商品基本信息（名称、规格、SKU、供应链价格）
- 各平台搜索结果（商品标题、价格、图片链接、购买链接）
- 价格对比结果（最低价平台标识、价格差异百分比）

## 注意事项

1. **反爬机制**：为避免被网站封禁，工作流已实现基本的反爬机制，包括随机User-Agent和请求延迟
2. **平台适配**：不同电商平台的页面结构可能会变化，需要定期更新解析逻辑
3. **数据准确性**：由于网络环境和页面结构的变化，价格数据可能存在一定误差
4. **性能优化**：对于大量商品的处理，可能需要优化性能和并发处理

## 扩展建议

1. **添加更多电商平台**：在 `config.py` 中添加新平台配置，并在 `price_collector.py` 中实现对应的采集逻辑
2. **优化搜索策略**：改进关键词构建算法，提高搜索准确性
3. **添加数据可视化**：集成数据可视化库，生成价格趋势图表
4. **实现定时任务**：设置定时任务，定期执行价格对比
5. **添加API接口**：提供RESTful API，方便与其他系统集成

## 故障排除

- **数据加载失败**：检查输入文件格式是否正确，或URL是否可访问
- **价格采集失败**：检查网络连接，或平台页面结构是否变化
- **验证失败**：检查商品规格描述是否清晰，或平台商品信息是否完整
- **导出失败**：检查输出目录权限，或磁盘空间是否充足
